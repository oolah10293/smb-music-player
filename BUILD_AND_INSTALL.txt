SMB Music v0.5.0 — standalone build/install

1. Clone or download this repository to a local folder.
2. Open its root in Android Studio with Java 17.
3. If gradle-wrapper.jar is missing, run SETUP_GRADLE_WRAPPER.bat
   or ./gradlew; the wrapper download is checksum-verified.
4. Install Android SDK 36 and Build Tools 36.0.0, then sync Gradle.
   No NDK, CMake or Snapclient preparation is needed.
5. Connect an Android device with USB debugging and run the app.

applicationId: com.smbmusic.player
versionCode: 16
versionName: 0.5.0
Minimum Android: 8.0 / API 26

Build checks:
./gradlew :app:assembleDebug :app:testDebugUnitTest --max-workers=2
./gradlew :app:lintDebug -PapiCompatibilityCheck --max-workers=2

This is standalone SMB Music. House Music is a separate future app.
There are no HOUSE settings, transfers or house-audio-server dependencies.
Use your existing SMB address, username and password. No Pi/S3 update.

CI creates a debug APK and matching source archive. The CI certificate can
change between releases, so Android may require uninstalling the older APK.
Save SMB connection details before uninstalling; uninstall clears app data.
See docs/RELEASE_0.5.0.md for exact build/artifact/signing verification.
