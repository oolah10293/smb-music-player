SMB Music Player v0.4.1 — build/install

1. Clone or download this repository to a LOCAL folder.

2. Open the repository root in Android Studio.

3. If Android Studio reports that gradle/wrapper/gradle-wrapper.jar is missing,
   run SETUP_GRADLE_WRAPPER.bat once. It downloads the official Gradle 9.6
   wrapper JAR and verifies its SHA-256 before using it.

4. Install Android SDK 36, Build Tools 36.0.0, NDK 28.2.13676358,
   and CMake 3.22.1. Use Java 17. Run python3 native/prepare.py from
   the repository root to fetch checksum-pinned receiver sources/licenses.
   Then let Gradle sync. See native/README.md for receiver build details.

5. Connect an Android device with USB debugging enabled.

6. Click the green Run button for the app configuration.
